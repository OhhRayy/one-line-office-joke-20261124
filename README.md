## What it does

`main.py` writes one office joke to `/output/entry.txt`. The program is deterministic (the same
bytes on every run), uses no network, and needs no input.

The line:

> I asked HR for a raise and they gave me a mindfulness app, so now I'm calmly underpaid.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
